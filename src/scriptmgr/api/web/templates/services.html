Always-On Services

Always-on services are scripts wrapped as Windows services that restart automatically on failure. Register a script here, then run install-service.ps1 as Administrator (or use NSSM) to install it. The service will call POST /api/services/heartbeat periodically to report its status.

QUICK INSTALL GUIDE

  1. Register the script above to get its service name
  2. Open PowerShell as Administrator
  3. Install with NSSM: nssm install <ServiceName> "C:\path\to\script.py"
  4. Set restart policy: nssm set <ServiceName> AppRestartDelay 5000
  5. Start: nssm start <ServiceName>
  6. The service will now auto-restart on crash and survive reboots
